# Third-party notices

This wrapper packages an independently maintained checkout of PokeRogue and its asset and localization repositories. Their licenses, credits, REUSE metadata, exact Git revisions, and applicable notices are copied into the packaged application's `resources/licenses` directory by `npm run build:game`.

PokeRogue is a fan game and includes material whose licensing status varies. Review the upstream repository's `README.md`, `LICENSE`, `CREDITS.md`, `REUSE.toml`, and `LICENSES` directory before distributing any build. Files in the upstream assets repository without explicit licensing metadata may have no stated copyright license. This project is configured for private, non-commercial use and does not grant rights beyond those provided by the respective rights holders.
